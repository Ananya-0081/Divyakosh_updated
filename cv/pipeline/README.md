# DivyaKosh CV Pipeline

This package implements the three-outcome inference pipeline for the DivyaKosh smart donation box.

## Files

| File | Purpose |
|---|---|
| `divyakosh_pipeline.py` | Core pipeline engine: ACCEPT_NOTE / REJECT_NOT_NOTE / REVIEW |
| `calibrate_thresholds.py` | Threshold sweep using validation set only. Saves `threshold_config.json`. |
| `evaluate_pipeline.py` | Evaluation on held-out test + real-camera challenge sets. |
| `threshold_config.json` | Generated by calibration. Loaded by pipeline at runtime. |
| `threshold_calibration_report.json` | Full calibration sweep results. |
| `pipeline_evaluation_report.json` | Full evaluation metrics report. |

## Decision Logic

```
Image
  └─ Quality check (sharpness)
       ├─ TOO BLURRY → REVIEW (review_reason: "Image too blurry")
       └─ OK
            └─ Model A: P(NOTE)
                 ├─ <= reject_max  → REJECT_NOT_NOTE
                 ├─ in (reject_max, accept_min) → REVIEW
                 └─ >= accept_min  → Model B: denomination
                       ├─ top_prob < denom_accept_min → REVIEW
                       ├─ margin   < margin_min       → REVIEW
                       └─ both met → ACCEPT_NOTE (denomination confirmed)
```

## Usage

### Step 1 — Calibrate thresholds (once, val set only)

```bash
cd cv
.\.venv\Scripts\python.exe pipeline/calibrate_thresholds.py
```

### Step 2 — Evaluate pipeline

```bash
cd cv
.\.venv\Scripts\python.exe pipeline/evaluate_pipeline.py
```

### Step 3 — Single-image inference

```bash
cd cv
.\.venv\Scripts\python.exe pipeline/divyakosh_pipeline.py --image path/to/image.jpg
```

### Programmatic use

```python
from pipeline.divyakosh_pipeline import DivyaKoshPipeline
from PIL import Image

pipe = DivyaKoshPipeline()
result = pipe.predict(Image.open("image.jpg"))
print(result.decision, result.predicted_denomination, result.count_authorized)
```

## Constraints

- Checkpoints are **never overwritten**.
- Thresholds are **calibrated on val set only**.
- **Test and real_test sets** are used only in `evaluate_pipeline.py`, never in calibration.
- `count_authorized=True` **only for ACCEPT_NOTE**.
- Hardware, blockchain, database integration is **out of scope**.
